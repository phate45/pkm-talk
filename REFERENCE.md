## PKM Tools & Software

### Primary Tools Discussed

**Emacs**
- Open-source, extensible text editor
- Website: https://www.gnu.org/software/emacs/
- Description: Powerful editor with steep learning curve, acts as "operating system" for text-based workflows

**Org-mode**
- Emacs major mode for notes, planning, and authoring
- Website: https://orgmode.org/
- Description: Comprehensive plain-text organization system with outlining, TODO lists, code blocks, tables

**Obsidian**
- Knowledge base and note-taking application
- Website: https://obsidian.md/
- Description: Markdown-based, local-first PKM tool with graph view, backlinks, and extensive plugin ecosystem
- Pricing: Free for personal use, paid for commercial use

**Notion**
- All-in-one workspace and note-taking app
- Website: https://www.notion.so/
- Description: Collaborative, database-driven workspace tool
- Mentioned as: Alternative tool (valid choice if it works for you)

**Logseq**
- Privacy-first, open-source knowledge base
- Website: https://logseq.com/
- Description: Outliner-based note-taking with graph view and bidirectional linking
- Mentioned as: Alternative tool (valid choice if it works for you)

### Emacs Ecosystem Tools

**Org-babel**
- Component: Part of Org-mode
- Website: https://orgmode.org/worg/org-contrib/babel/
- Description: Literate programming - execute code blocks within Org documents, "code tangling"

**Magit**
- Git interface for Emacs
- Website: https://magit.vc/
- Description: Described as "best Git UI ever used" - comprehensive Git porcelain for Emacs

**Elfeed**
- RSS/Atom feed reader for Emacs
- Website: https://github.com/skeeto/elfeed
- Description: Fast, extensible RSS reader integrated into Emacs workflow

**Org-roam**
- Roam Research replica for Emacs
- Website: https://www.orgroam.com/
- Description: Zettelkasten implementation for Emacs using Org-mode, backlinks panel

## Obsidian Plugins

### Essential Plugins Highlighted

**Tasks**
- Plugin for: Advanced task management
- Repository: https://github.com/obsidian-tasks-group/obsidian-tasks
- Description: Sophisticated task tracking with due dates, priorities, recurrence. Query language for task views.

**QuickAdd**
- Plugin for: Rapid note capture
- Repository: https://github.com/chhoumann/quickadd
- Description: Macros for capturing bookmarks, ideas, meeting notes. Hotkey → template → done.

**Recent Files**
- Plugin for: Quick navigation
- Description: List of recently opened notes for fast access to last 5-10 files

**Git**
- Plugin for: Version control integration
- Repository: https://github.com/denolehov/obsidian-git
- Description: Automatic Git backup and version control within Obsidian

**Calendar**
- Plugin for: Calendar view
- Repository: https://github.com/liamcain/obsidian-calendar-plugin
- Description: Visualize daily notes in calendar format

**Advanced Tables**
- Plugin for: Markdown table editing
- Repository: https://github.com/tgrosinger/advanced-tables-obsidian
- Description: Spreadsheet-like table navigation and formatting

**Heading Shifter**
- Plugin for: Outline manipulation
- Repository: https://github.com/k4a-l/obsidian-heading-shifter
- Description: Quickly adjust heading levels in documents

## Methodologies & Frameworks

### Organizational Systems

**Zettelkasten**
- Origin: Niklas Luhmann (German sociologist)
- Principles: Atomic notes (1 idea = 1 note), bidirectional linking, emergent structure
- Website: https://zettelkasten.de/
- Description: Slip-box method for interconnected knowledge management

**PARA Method**
- Origin: Tiago Forte
- Structure: Projects (time-bound work), Areas (ongoing responsibilities), Resources (reference materials), Archive (inactive items)
- Purpose: Prevents "folder chaos" with actionability-based organization
- Website: https://fortelabs.com/blog/para/

## AI & Integration Technologies

### AI Tools

**ChatGPT**
- Provider: OpenAI
- Website: https://chat.openai.com/
- Description: Conversational AI with broad knowledge but zero personal context
- Mentioned as: Complementary to PKM (breadth vs depth)

**Claude**
- Provider: Anthropic
- Website: https://www.anthropic.com/claude
- Description: AI assistant used with MCP for vault automation
- Use case: Reading/writing to Obsidian vault, generating commit messages, weekly synthesis

### Protocols & Technologies

**MCP (Model Context Protocol)**
- Description: Protocol allowing AI tools to securely interact with local systems
- Use case: Claude reading/writing directly to Obsidian vault
- Enables: Weekly synthesis, work log automation, inbox processing, link suggestions, atomic commits
- Website: https://modelcontextprotocol.io/

**Markdown**
- Description: Lightweight markup language with plain text formatting
- Website: https://www.markdownguide.org/
- Use case: Portable, human-readable note format across PKM tools

**WikiLink Syntax**
- Format: `[[Note Title]]`
- Description: Internal linking syntax used in Obsidian and other PKM tools
- Purpose: Creates bidirectional links between notes

## E-ink Hardware (Note-Taking Devices)

### Tablets Mentioned

**Onyx Boox**
- Description: Full Android + Google Play, most flexible
- Strengths: E-reader, notes, PDF annotation, app support, adjustable backlighting
- Considerations: Writing feel less "paper-like" than competitors
- Website: https://www.boox.com/

- Description: Note-focused device with ceramic stylus
- Strengths: Excellent pen-on-paper feel, efficient OS
- Considerations: Fewer apps, some models lack backlighting
- Website: https://supernote.com/

**Remarkable**
- Description: Ultra-minimalist, distraction-free writing device
- Strengths: Best writing/drawing experience, most "paper-like" feel
- Considerations: Limited app ecosystem, may lack backlighting
- Website: https://remarkable.com/
